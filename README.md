# آمادبان

سامانه تحت وب آماد و پشتیبانی بیمارستان فوق‌تخصصی امام سجاد (ع) فراجا.

## اجرای سریع

روی میزبان دارای Docker و Compose، فایل `.env.example` را به `.env` کپی کنید. رمز پایگاه و رمز اولیه مدیر را جداگانه تعیین کنید. رمز مدیر حداقل ۱۲ نویسه است. سپس اجرا کنید.

```sh
docker compose up -d --build
docker compose ps
```

نشانی پیش‌فرض روی خود سرور `http://127.0.0.1:8088` و نام کاربری اولیه `admin` است. مدیر از منوی «کاربران»، حساب افسرعامل، انباردار و کارتکس می‌سازد. رمز اولیه فقط در ایجاد نخستین حساب روی پایگاه خالی استفاده می‌شود.

## راه‌اندازی روی LAN ایزوله

ایمیج‌ها را روی دستگاهی که به مخازن لازم برای ساخت دسترسی دارد بسازید. فایل `.env` واقعی هر محیط را روی همان میزبان نگه دارید.

```sh
docker compose build
docker compose pull db
docker save -o amadban-images.tar amadban-web postgres:17-alpine
```

ایمیج‌ها، فایل Compose و نمونه تنظیمات را به میزبان LAN منتقل کنید. سپس با تنظیمات همان میزبان اجرا کنید.

```sh
docker load -i amadban-images.tar
docker compose up -d --no-build --pull never
```

برای محیط بیمارستان، `AMADBAN_BIND_ADDRESS` را روی نشانی داخلی مجاز تنظیم کنید. اگر ترافیک خارج از میزبان می‌رود، دسترسی را به LAN مجاز و HTTPS مورد تأیید فناوری اطلاعات محدود کنید.

## انتشار تست کنار فروشگاه

Codex روی PC از همین مخزن و یک کامیت مشخص استفاده می‌کند. مسیر، پروژه Compose، سرویس، پورت و داده آمادبان مستقل‌اند. ابتدا بررسی شود پورت انتخابی آزاد است. پیش‌فرض loopback با تونل SSH قابل مشاهده است. فایل‌ها، وب‌سرور، پورت‌های ۸۰ و ۴۴۳، سایت‌مپ و robots.txt فروشگاه دست‌نخورده بمانند. آمادبان هدر `X-Robots-Tag` می‌فرستد و صفحات عملیاتی ورود می‌خواهند. وضعیت صفحه اصلی و یک محصول فروشگاه قبل و بعد از اجرا بررسی شود.

```sh
docker compose stop
```

این فرمان سرویس آمادبان را متوقف می‌کند و داده‌هایش را حفظ می‌کند. دستور حذف حجم‌ها هنگام توقف اجرا نشود.

## پشتیبان عملیاتی

```sh
docker compose exec -T db pg_dump -U amadban -d amadban -Fc > amadban-backup.dump
```

فایل پشتیبان شامل مدارک پیوست است. بازیابی را روی پایگاه جدا انجام دهید تا داده عملیاتی درگیر آزمون نشود.
