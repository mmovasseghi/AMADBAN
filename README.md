# آمادبان

سامانه تحت وب آماد و پشتیبانی بیمارستان فوق‌تخصصی امام سجاد (ع) فراجا.

## اجرای سریع

روی میزبان دارای Docker و Compose، فایل `.env.example` را به `.env` کپی کنید. رمز پایگاه و رمز اولیه مدیر را جداگانه تعیین کنید. رمز مدیر حداقل ۱۲ نویسه است. سپس اجرا کنید.

```sh
docker compose up -d --build
docker compose ps
```

نشانی پیش‌فرض روی خود سرور `http://127.0.0.1:8088` و نام کاربری اولیه `admin` است. مدیر از منوی «کاربران»، حساب افسرعامل، انباردار و کارتکس می‌سازد. رمز اولیه فقط در ایجاد نخستین حساب روی پایگاه خالی استفاده می‌شود.

## راه‌اندازی روی LAN ایزوله

ایمیج‌ها را روی دستگاهی که به مخازن لازم برای ساخت دسترسی دارد بسازید. فایل `.env` واقعی هر محیط را روی همان میزبان نگه دارید.

```sh
docker compose build
docker compose pull db
docker save -o amadban-images.tar amadban-web postgres:17-alpine
```

ایمیج‌ها، فایل Compose و نمونه تنظیمات را به میزبان LAN منتقل کنید. سپس با تنظیمات همان میزبان اجرا کنید.

```sh
docker load -i amadban-images.tar
docker compose up -d --no-build --pull never
```

برای محیط بیمارستان، `AMADBAN_BIND_ADDRESS` را روی نشانی داخلی مجاز تنظیم کنید. اگر ترافیک خارج از میزبان می‌رود، دسترسی را به LAN مجاز و HTTPS مورد تأیید فناوری اطلاعات محدود کنید.

## انتشار تست کنار فروشگاه

Codex روی PC از همین مخزن و یک کامیت مشخص استفاده می‌کند. مسیر، پروژه Compose، سرویس، پورت و داده آمادبان مستقل‌اند. ابتدا بررسی شود پورت انتخابی آزاد است. پیش‌فرض loopback با تونل SSH قابل مشاهده است. فایل‌ها، وب‌سرور، پورت‌های ۸۰ و ۴۴۳، سایت‌مپ و robots.txt فروشگاه دست‌نخورده بمانند. آمادبان هدر `X-Robots-Tag` می‌فرستد و صفحات عملیاتی ورود می‌خواهند. وضعیت صفحه اصلی و یک محصول فروشگاه قبل و بعد از اجرا بررسی شود.

```sh
docker compose stop
```

این فرمان سرویس آمادبان را متوقف می‌کند و داده‌هایش را حفظ می‌کند. دستور حذف حجم‌ها هنگام توقف اجرا نشود.

## پشتیبان عملیاتی

```sh
docker compose exec -T db pg_dump -U amadban -d amadban -Fc > amadban-backup.dump
```

فایل پشتیبان شامل مدارک پیوست است. بازیابی را روی پایگاه جدا انجام دهید تا داده عملیاتی درگیر آزمون نشود.

## راهنمای شروع گردش کار

1. رئیس آماد حساب‌های فردی، اشخاص امضاکننده با درجه یا رتبه، نام‌های چاپی و کدهای اعتباری را ثبت می‌کند. نشان‌های محلی پیش‌فرض در بسته‌اند و در «نشان و امضا» قابل جایگزینی با فایل اصلی سازمان‌اند. کارهای ثبت‌شده همه نقش‌ها در «اطلاعیه‌های آماد» با نام کاربر و پیوند جزئیات برای رئیس دیده می‌شوند.
2. انباردار موجودی روز نخست را با شمارش واقعی ثبت می‌کند. افسرعامل فاکتور جدید را با نام اقلام عین فاکتور وارد می‌کند. شماره سند در مرحله صدور ساخته می‌شود. برای فاکتور انباری، انباردار از صفحه پرونده برای هر قلم کالای متناظر موجود را انتخاب می‌کند یا کد را خالی می‌گذارد تا کالای جدید ساخته شود؛ این تطبیق برای بار بعد حفظ می‌شود و نام چاپی فاکتور تغییر نمی‌کند.
3. در خرید اعتباری افسرعامل پیش‌پرداخت می‌سازد، حساب فروشنده را انتخاب می‌کند و بعد از عملیات بیرون از سامانه، پرداخت را ثبت می‌کند. خرید نقدی هنگام صدور سند پرداخت‌شده ثبت می‌شود.
4. کارتکس پس از ثبت در سامانه جداگانه فراجا، شماره نوشته‌شده روی سند و تاریخ را در «ثبت سریع کارتکس» وارد می‌کند. مدارک لازم در صفحه پرونده دیده می‌شوند. رئیس و افسرعامل تحویل، برگشت و بسته‌شدن را ثبت می‌کنند.
5. برای سند هر بخش، کارشناس همان بخش را در پرونده انتخاب کنید؛ این فرد از تحویل‌گیرنده حواله انبار مستقل است. صورت‌جلسه در صورت نیاز یک امضاکننده اضافه هم می‌پذیرد. پیش‌پرداخت خرید از اقلام اول و آخر همان فاکتور، کد، فروشنده و حساب بانکی پر می‌شود. پیش‌پرداخت تنخواه را افسرعامل در صفحه «تنخواه» ثبت می‌کند؛ شماره شروع فاکتور تنخواه را بار نخست دستی می‌دهد و شماره‌های بعدی خودکارند. این برگه اعتباری مصرف نمی‌کند.
6. پس از راه‌اندازی، برای نمونه‌گیری فوری چاپ یک سند و فرم صیاد A4 را از همین محیط بررسی کنید. چاپ فیش بانکی طبق تصمیم نهایی از سامانه حذف شده است.
7. برای رساندن کالا به بخش، انباردار ابتدا بخش و شخص تحویل‌گیرنده را تعریف می‌کند. در «ارسال کالا به بخش» مقصد، شخص، کالاها و مقدار را ثبت می‌کند. سامانه موجودی را کم و برگه A4 شماره‌دار با جای دو امضا آماده می‌کند. تعداد نسخه در صفحه چاپ انتخاب می‌شود. **یک نسخه امضاشده حتماً در انبار نگهداری شود**؛ اسکن این برگه لازم نیست.
8. در «گزارش تحویل انبار» بازه شمسی، بخش و کالا را انتخاب کنید. جمع تحویل هر کالا به هر بخش، شماره برگه‌ها و نام تحویل‌گیرنده دیده می‌شود؛ ردیف‌های کامل نیز برای Excel به‌صورت CSV دریافت می‌شوند.
