# راهنمای نصب آزمایشی جدا از فروشگاه

این راهنما برای Codex روی PC است. نسخه مبنا شاخه `main` مخزن خصوصی AMADBAN است. سرور فروشگاه در این نشست دست‌کاری نشده است. نصب باید در پوشه و پروژه Compose مخصوص آمادبان انجام شود؛ هیچ فایل، سرویس، پایگاه، درگاه ۸۰/۴۴۳، تنظیم وب‌سرور، robots.txt یا سایت‌مپ فروشگاه تغییر نکند.

## پیش از اجرا

1. وضعیت فعلی فروشگاه، سرویس‌های Docker و درگاه‌های باز را ثبت کنید. پاسخ صفحه اصلی و یک صفحه محصول فروشگاه را به‌عنوان مبنا نگه دارید.
2. مخزن را در مسیر جدا، مثلاً `/opt/amadban-test` دریافت کنید. کد را از یک کامیت مشخص روی `main` بخوانید و شناسه کامیت را در گزارش اجرا ذکر کنید.
3. فایل `.env.example` را به `.env` کپی کنید، دو رمز قوی و مجزا تعیین کنید و فایل را فقط برای مالک قابل‌خواندن کنید. رمزها در گزارش، Git یا خروجی ترمینال ثبت نشوند. `AMADBAN_BIND_ADDRESS=127.0.0.1` و یک درگاه آزاد مانند `8088` را نگه دارید.
4. `docker compose config` و آزاد بودن درگاه انتخابی را بررسی کنید. نام پروژه Compose در فایل `amadban` است؛ اگر پروژه‌ای با این نام روی میزبان وجود دارد، قبل از اجرا نام اختصاصی دیگری برای همین نصب تعیین کنید.

## اجرا و مشاهده

```sh
docker compose up -d --build
docker compose ps
curl -I http://127.0.0.1:8088/Login
```

برای مشاهده از PC، تونل SSH به `127.0.0.1:8088` بسازید و مرورگر همان PC را به نشانی محلی تونل ببرید. برای نمایش آزمایشی، اتصال مستقیم دامنه فروشگاه یا مسیر URL فروشگاه لازم نیست. برنامه هدر `X-Robots-Tag: noindex, nofollow` دارد و صفحه‌های کاری به ورود نیاز دارند.

## کنترل نهایی و بازگشت

- با حساب اولیه مدیر وارد شوید، کاربران آزمایشی را در پایگاه مستقل بسازید و یک سند، حواله انبار و فرم صیاد A4 را در پیش‌نمایش چاپ بررسی کنید. روی چاپگر بیمارستان و سیستم ویندوز ۷ هنوز آزمون فیزیکی انجام نشده است.
- دوباره صفحه اصلی و همان صفحه محصول فروشگاه را کنترل کنید و درگاه‌ها و سرویس‌های آن را با مبنا مقایسه کنید.
- اگر لازم شد آمادبان را متوقف کنید، از پوشه همین پروژه `docker compose stop` بزنید. برای توقف، حجم داده حذف نشود. پشتیبان‌گیری با دستور README انجام می‌شود.
